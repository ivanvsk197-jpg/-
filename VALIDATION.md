# Перевірки

Пройдено локально 1 жовтня 2026:
- Установлення зафіксованих Python-залежностей.
- Компіляція app.py та перевірка синтаксису JavaScript через node --check.
- HTTP /health, відмова без пароля, доступ із паролем.
- Створення правила через HTTP та відображення його в спільному API.
- Виявлення нового спіну при повторенні попереднього числа.
- Збереження й відновлення спінів та правил із checkpoint.
- Один сигнал при вході в умову; повторний після виходу і нового входу.
- Створення правила через реальний обробник меню з імітацією Telegram API.

Не перевірено: збір даних із живого джерела, доставку Telegram-повідомлень, вигляд сторінки на реальних мобільних пристроях, збірку Docker та розгортання Railway. Початкові адаптивні стилі збережено. Ці перевірки потребують запуску сервісу та налаштування токена.
