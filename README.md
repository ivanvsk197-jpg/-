# Моніторинг рулеток — GitHub + Railway

Вебсторінка й моніторинг працюють на сервері без відкритого браузера на вашому комп’ютері. Сайт має адаптивні картки й горизонтальне прокручування великих таблиць на телефоні. Дані та правила спільні для всіх пристроїв. Telegram: /start або /menu.

## Запуск
1. Розпакуйте архів. Завантажте в корінь свого GitHub-репозиторію app.py, requirements.txt, Dockerfile, railway.json, README.md і файли .gitignore та .dockerignore. Не завантажуйте початковий файл із токеном.
2. На https://railway.com/new виберіть розгортання з GitHub та цей репозиторій. Dockerfile встановить Python, Chromium і залежності.
3. У Variables задайте:
   - DASHBOARD_PASSWORD — ваш довгий пароль для сайту (обов’язково).
   - DASHBOARD_USER — admin або інше ім’я входу.
   - TELEGRAM_BOT_TOKEN — ваш поточний токен бота.
   - TELEGRAM_CHAT_ID — ID вашого особистого чату з ботом.
   - DATA_DIR — /data.
4. Додайте Volume із Mount Path /data. Без нього дані можуть зникнути після перевстановлення сервісу.
5. Після запуску: Settings → Networking → Generate Domain. Відкрийте отриманий HTTPS URL на будь-якому пристрої. Введіть ім’я admin і заданий пароль. Власний домен купувати не потрібно.
6. Додайте PUBLIC_URL з отриманою HTTPS адресою: в Telegram з’явиться кнопка відкриття сайту.
7. Напишіть боту /start. Стару копію програми з цим ботом вимкніть: для отримання Telegram-команд має працювати тільки один процес. Railway: одна репліка; не вмикайте засинання сервісу, якщо потрібен безперервний моніторинг.

За вашим вибором використовується той самий токен через Variables Railway. У репозиторії секретів немає. Файл .env.example — приклад назв змінних, він не завантажується програмою автоматично.

## Меню Telegram
＋ Додати правило → показник → ≥ / = / ≤ → надішліть поріг числом.
📋 Мої правила — перегляд та видалення натисканням.
📊 Статус — кількість зібраних спінів для кожної рулетки.
🌐 Відкрити сайт — доступно після налаштування PUBLIC_URL.

Правила застосовуються до всіх дев’яти рулеток. ALL — усі числові показники. Показники меню відповідають коду: Red/Black, дюжини 1st/2d/3d, колони 1col/2col/3col, ALT, сектори, S (трійки), L (шістки), C (кути), NGR (неперекривні групи сусідів), NUM0–NUM36 (окремі числа). Сигнал надходить один раз при вході в умову; коли умова перестає виконуватися, він може спрацювати знову. Початкові сигнали серій дюжин і колон 5+ також збережено.

Після першого старту статистика накопичується з нових спінів. Кнопка «Новий сеанс» обнуляє спіни й історію для всіх пристроїв, але зберігає правила. На Volume зберігаються останні 500 спінів на рулетку, історія, максимуми, правила й стан сигналів. Через обмеження 500 спінів більші значення невипадіння не відстежуються точно.

## Перевірка та межі
Локальні перевірки описані в VALIDATION.md. Роботу з живим джерелом та вашим Telegram треба перевірити після розгортання. Сайт-джерело може змінити HTML, обмежити доступ серверу або показати CAPTCHA; код її автоматично не розв’язує. При тривалій зупинці неможливо відновити результати, яких уже немає у видимій історії джерела. Збіг однакових історій спінів також може приховати новий результат.

/health перевіряє доступність вебсервера, а не свіжість даних джерела. Якщо цифри не змінюються, перевірте Logs і час останнього оновлення. Монітор автоматично перезапускається після аварії Chromium. Вартість залежить від ресурсів Railway; безперервний Chromium споживає пам’ять і CPU.

Статистика описує попередні результати й не гарантує напрям наступного спіну.

## Локально
Python 3.12; `pip install -r requirements.txt`; `python -m playwright install --with-deps chromium`; налаштуйте змінні оточення й виконайте `python app.py`. Без TELEGRAM_BOT_TOKEN та TELEGRAM_CHAT_ID сайт працює, Telegram вимкнений. На Railway пароль обов’язковий; локально без пароля не відкривайте сервіс в інтернет.
